Privacy starts with clear boundaries

WealthFlow uses account-scoped records and established authentication controls. No unsupported security guarantees.

Security information, plainly stated

Passwords are stored as bcrypt hashes rather than plain text. Sign-in uses an HttpOnly session cookie, and financial records are associated with the signed-in user. Cookie transport security depends on the deployment configuration; use HTTPS for remote deployments.

WealthFlow does not connect to banks in this installation. Financial information is entered or imported by the account holder. The AI chat requires a server-side Gemini API key and sends relevant account summaries to that provider when used.
